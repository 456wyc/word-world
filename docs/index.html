功能

查词、收录、复习，一条链路都在浏览器里完成。

划词即查

选中单词看音标、词性释义、例句与中文译义；选中整句看整句译文，支持 Web Speech 发音。

自动收录

查过的词自动进入本地生词本，重复查询只累加次数，不会产生重复条目。

三种复习形态

底部字幕条、飘过弹幕、右下角角落卡片，可设置间隔（60 秒–30 分钟）与停留时长。

一键评分

认识 / 模糊 / 不认识，按简化 SRS 推进复习间隔，并提示下次复习时间。

生词本管理

搜索、按类型筛选、排序、添加备注、删除，支持导入导出 JSON 备份。

数据源可选

默认免费词典 + 翻译接口；也可填任意 OpenAI 兼容接口，AI 失败自动回退免费接口。

工作原理

后台 Service Worker 是唯一的数据与网络网关，网页只负责显示。

  1. 1

    网页划词

    Content script 在 Shadow DOM 中渲染划词图标与卡片，和页面样式互不影响。

  2. 2

    后台查询并收录

    Service Worker 请求词典/翻译或 AI 接口，结果写入本地生词本并做 7 天缓存。

  3. 3

    浏览时浮现复习

    按 SRS 阶梯选词，在设定的间隔后以所选形态浮现，评分后推进下一次复习时间。

隐私

这个扩展不认识你是谁，也不需要知道。

只存本地

生词、设置、缓存与 API Key 都在本机 chrome.storage.local，没有账号、没有云同步。

没有遥测

不含任何统计、崩溃上报或行为追踪代码，也不会把数据分享给第三方。

只在你划词时联网

请求仅发往免费词典/翻译接口，或你在设置里自己填写的 AI 接口，内容是选中的文本。

密钥不外泄

API Key 只保存在本机，导出 JSON 时会被剔除，也不会传入网页上下文。

完整说明见 隐私政策。

常见问题

怎么从源码加载？

克隆仓库后执行 npm install、npm run icons、npm run build， 然后在 chrome://extensions 开启开发者模式 →「加载已解压的扩展程序」→ 选择 dist/。

免费接口不可用怎么办？

Google 公开翻译端点在部分网络环境不可达，扩展会自动回退 MyMemory；更稳定的做法是在设置里切换到 AI 模式， 填写任意 OpenAI 兼容的 Base URL、API Key 与模型。

会不会打扰我浏览？

默认每 3 分钟最多一次，且页面隐藏、输入框聚焦、有选中文本、全屏播放时都不会弹出； 也可以对指定站点永久暂停，或在 popup 里一键关闭。

支持哪些浏览器？

只支持 Chrome / Edge（Chrome 110+）。chrome:// 页面、扩展商店与 PDF 阅读器页面无法注入。

数据能导出吗？

可以。设置页与生词本页都支持导出 JSON（含词条与设置），并可再导入回来，导入支持合并模式。
