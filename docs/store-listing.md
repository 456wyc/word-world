## 2. 简短简介（商店卡片，≤132 字符）

```
网页划词即查词翻译，自动收进生词本，并按记忆曲线在浏览时以字幕、弹幕或卡片浮现复习。
```

## 3. 详细描述（商店详情页）

```
Word World 让你在浏览网页时随手记单词：选中文字，点一下「译」图标就能看到释义、音标、例句和中文译文，结果自动收进生词本；之后按简化的间隔重复（SRS）算法，在你继续浏览时以轻量浮层浮现复习，不用专门打开 App。

主要功能

· 划词即查：选中单词看音标、词性释义、例句与中文译义；选中整句看整句译文，支持朗读发音。
· 自动收录：查过的词自动进入本地生词本，重复查询只增加次数，不产生重复条目。
· 三种复习形态：底部字幕条、飘过弹幕、右下角角落卡片，可设置间隔（60 秒–30 分钟）与停留时长。
· 认识 / 模糊 / 不认识：一键评分，自动推进复习间隔，并提示下次复习时间。
· 生词本管理：搜索、按类型筛选、排序、添加备注、删除，支持导入导出 JSON 备份。
· 站点暂停：可对指定网站（如视频、邮箱）关闭浮层，也可一键暂停当前站点。
· 数据源可选：默认使用免费词典与翻译接口；也可以填写任意 OpenAI 兼容接口（Base URL / API Key / 模型），AI 失败时自动回退免费接口。

隐私

· 数据只存在你本机（chrome.storage.local），没有账号、没有云同步。
· 没有遥测和统计代码，不收集任何个人信息。
· 只有你主动划词查词时才会联网，请求仅发往免费接口或你自己配置的 AI 接口。
· API Key 只保存在本机，导出文件时会被剔除。

说明

免费接口在部分网络环境下可能不可达或有限流，可在设置中改用 AI 接口。仅支持 Chrome / Edge（Chrome 110+）；chrome:// 页面、扩展商店与 PDF 阅读器页面无法注入。
```

## 5. 隐私声明填写要点（后台「隐私」标签页）

- **单一用途**：网页划词查询与生词复习。
- **数据使用声明**（按 Disclosures 勾选）：
  - 不收集网站内容、不收集网页浏览活动（扩展只在用户划词时读取选中文本）；
  - 不收集个人身份信息、不收集位置、不收集用户通信内容；
  - 无遥测、不与第三方共享数据（除用户主动查词时发往所选数据源的文本）。
- **权限理由**：
  - `storage` / `unlimitedStorage`：本地保存生词本、设置与缓存。
  - `host_permissions: <all_urls>`：① 在任意网页注入划词界面，实现选中文字即查；② 允许用户自行配置任意 AI 接口地址并请求。
- **隐私政策链接**：填写本仓库 `PRIVACY.md` 的公开地址（GitHub 链接或 GitHub Pages）。
